== Introduction

The RISC-V S-level Physical Memory Protection (SPMP) for Hypervisor integrates the SPMP and Hypervisor extensions by providing a two-stage SPMP. It introduces vSPMP, a first-stage SPMP, in control of VS-mode allowing a guest supervisor to specify memory protection policies within its guest physical address space. Guest VS/VU-mode accesses are further checked by the SPMP as defined by the RISC-V S-level Physical Memory Protection (SPMP) specification, Version 1.0.
